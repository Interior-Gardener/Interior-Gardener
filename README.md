## 🌟 Featured Projects

### 🌍 GeoSwipe — Interactive Earth Exploration using Hand Gestures

> 🏆 Selected for **CIIA-5** at Nehru Science Centre &nbsp;·&nbsp; 🥈 AI-Robo Festival Runner-up

An immersive learning platform that changes how people explore the world's cultural heritage: instead of clicking
buttons, users navigate a fully interactive 3D Earth with **hand gestures** driven by computer vision.

**Highlights** — Interactive 3D globe · Real-time gesture control via MediaPipe · Heritage site explorer ·
Multimedia StoryBook mode · Location-based quizzes · JSON-driven content tooling, so new sites are added without
touching application code

### 🏭 Roll Shop Management System — JSW Steel

> 🏭 Built and deployed during my internship at **JSW Steel**

An enterprise web application that digitally manages the full lifecycle of steel rolls — arrival, maintenance,
status, disposal — replacing a manual, error-prone tracking process.

**Modules** — Roll tracking & lifecycle management · Maintenance records · Status tracking · Reporting dashboards ·
Role-based authentication

**Impact** — Improved asset visibility and data accuracy, and cut manual tracking errors for shop staff and
management.
