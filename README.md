## 🌍 GeoSwipe — Interactive Earth Exploration

<table>
<tr>
<td width="65%">

### 🚀 Overview

GeoSwipe is an immersive learning platform that transforms how users explore the world's cultural heritage.

Instead of clicking buttons, users can navigate a fully interactive 3D Earth using **hand gestures** powered by Computer Vision.

### ✨ Features

- 🌍 Interactive 3D Globe
- 🤚 Gesture Controls using MediaPipe
- 🏛 Heritage Site Explorer
- 📖 StoryBook Mode
- 🧠 AI-powered learning
- 🗺 Interactive Maps
- 🌤 Live Weather
- 📰 Heritage News
- 🎯 Quiz Mode
- 🏆 Multiplayer Quiz
- 📍 Route Planning
- 📄 Trip Planner

### 🛠 Tech Stack

Three.js • React • Node.js • Express • MongoDB • Socket.IO • MediaPipe • OpenCV • MapTiler • Sketchfab
