## 🌟 Featured Projects

### 🌍 GeoSwipe — Interactive Earth Exploration using Hand Gestures

GeoSwipe is an immersive learning platform that transforms how users explore the world's cultural heritage — instead of clicking buttons, users navigate a fully interactive 3D Earth using **hand gestures** powered by computer vision.

**Features:** Interactive 3D globe · Gesture controls via MediaPipe · Heritage site explorer · Multimedia StoryBook mode · Location-based quizzes · JSON-driven content tooling for easy expansion

**Tech Stack:** Python (MediaPipe) · Three.js · Node.js · Express.js · Socket.IO

**Achievement:** 🏆 Selected for **CIIA-5** at Nehru Science Centre

🔗 [View Project](https://drive.google.com/file/d/1peVfFWev9K2vw0RJ45yoXmNOEkO6kqlw/view?usp=sharing)

---

### 🧪 Atomix — Your Personal AI-Powered Chemistry Lab

A virtual chemistry laboratory built in Unity where students can safely perform free-hand experiments while interacting with an **AI voice-based tutor**, combining education, AI, and immersive simulation to make chemistry engaging.

**Tech Stack:** Unity · AI Voice Integration

**Achievement:** 🥇 Winner — **Intech 2025–26**

🔗 [View Project](https://drive.google.com/file/d/1cEV9zK8EQ_creOWvp3BYRbzySHghpPSn/view?usp=sharing)

---

### 🏭 Roll Shop Management System — JSW Steel Internship Project

An enterprise web application built during my internship at **JSW Steel** to digitally manage the complete lifecycle of steel rolls — from arrival to disposal — replacing manual, error-prone tracking.

**Modules:** Roll tracking & lifecycle management · Maintenance records · Status tracking · Reporting dashboards · User authentication

**Tech Stack:** Flask · Oracle Database · Python

**Impact:** Improved asset visibility and data accuracy while reducing manual tracking errors for shop staff and management.

🔗 [View Repository](https://github.com/Interior-Gardener/JSW_ROLL_SHOP_MANAGEMENT)

---

### 🤝 Skilll_Verse — A Skill Sharing Platform

A comprehensive platform designed to help users discover, manage, and enhance their skills through interactive modules and shared resources — built collaboratively as a team project.

**Tech Stack:** React.js · Node.js · Express.js · MongoDB

🔗 [View Repository](https://github.com/Kanavt15/Skill-Verse)
